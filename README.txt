Nubrii My Sweetheart — Birthday Website

Files:
- index.html: the website
- photos/: the four photos you uploaded

Preview:
Open index.html in a browser. Keep the photos folder beside it.

To publish free using GitHub Pages:
1. Sign in/create an account at https://github.com
2. Create a new public repository (for example: nubrii-birthday).
3. Upload index.html and the entire photos folder (with all four images).
4. Open repository Settings → Pages.
5. Under Build and deployment, select Deploy from a branch, choose main and / (root), then Save.
6. Wait for GitHub Pages to publish; it will show your website URL in Settings → Pages.
7. Send that URL to Nubrii.

To add more photos:
1. Put the new image in the photos folder.
2. Add another card inside the <div class="gallery"> section in index.html, for example:
   <article class="photo"><img src="photos/new-photo.jpg" alt="Nubrii photo"><p>A sweet memory 💗</p></article>
3. Upload the changed files again.

Note: This package is ready as website files, but it is not published online yet. You must upload it to a hosting service to get a shareable public URL.
